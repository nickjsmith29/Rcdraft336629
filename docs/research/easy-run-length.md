# Easy runs longer than the long run (#23, earlier repo #81)

Checked 23 Nov 2026. Sources marked "read" were opened and read. Numbers in brackets match SPEC.md section 12.

## The gap

The plan builder fills the week's time after the long run and quality sessions with easy runs. On few training days at high volume it can draft an easy run much longer than the long run, and past rule 5's long-run time cap. For example, a 10K plan on three days at 330 minutes a week starts with a 158-minute easy run beside a 105-minute long run. SPEC sets no limit on an easy run's length beyond the spike rule and the runner's max session length.

## What the sources say

- **The long run is the week's longest run.** Strength Running (Fitzgerald) defines it that way: "Quite simply, it's the longest run of the week," and "in any scenario, it's whatever run is the longest of the week" [31] (read). The Hansons excerpt calls the 16-mile long run "the longest training day" of its standard program and caps the long run at 25 to 30% of weekly mileage, after Daniels [11] (read).
- **Midweek runs.** Pfitzinger's medium-long run, as described for Active.com by Kevin Beck, is "commonly 10 to 15 miles" or 90 minutes to two hours, a run set apart from everyday runs [32] (read). The page gives no share of the long run, so it doesn't support a figure such as 75%.
- **Easy-run length limits.** None of the sources read sets a limit on an easy run's length. None compares easy runs with the long run by a number.
- **Injury data.** Garmin-RUNSAFE found overuse injury tracked a single run longer than the longest run of the previous 30 days [1]. It doesn't say which kind of run that is. The plan builder grows only the long run carefully (10 minutes a week), so an easy run longer than the long run becomes the week's spike-setting run without that care.

## Reading

Coaches treat the long run as the longest run of the week by definition. No study tests a limit on easy-run length, so any limit is coaching convention. "No easy run longer than the week's long run" follows the definition directly. A stricter share such as 75% of the long run has no source and would make three- and four-day weeks smaller. Evidence: weak (coaching sources only).

## Owner's decision

Option 1, "Cap at long run" (Nick, 23 Nov 2026, #23): no easy run is longer than the week's long run, and nothing goes past rule 5's long-run time cap or the runner's max session length; a week whose volume doesn't fit plans smaller with a note. Option not chosen: easy runs at most 75% of the week's long run (no source for the figure).

Follow-up decision, "Keep long workout days" (Nick, 23 Nov 2026, #70): on 3 and 4 day weeks, the easy time this limit holds back goes to the quality sessions' easy cool-down (hard minutes unchanged, each session up to the week's long run, the long-run cap and the max session length) before the week is planned smaller. Option not chosen: plan those weeks smaller, which would cut a 10K week at 330 minutes on 3 days to about 165 to 209 minutes. This ordering is coaching judgement, not a tested rule (heuristic).
